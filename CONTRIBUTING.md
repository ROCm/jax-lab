# Contributing to JAX Lab

Thank you for your interest in contributing to JAX Lab.

## Reporting Issues

Use [GitHub Issues](../../issues) to report bugs or request features. Include a clear description, steps to reproduce the issue, expected and observed behavior, and relevant environment details such as the operating system, GPU model, ROCm version, Python version, and JAX version.

For security vulnerabilities, do not open a public issue. Follow the reporting process described in [SECURITY.md](SECURITY.md).

## Pull Requests

1. Create a branch from `master`, either in your fork or in this repository if you have write access.
2. Make a focused change and update tests or documentation as needed.
3. Run the relevant tests locally.
4. Open a pull request against `master`. Describe what changed and why, and link any related issues.
5. Ensure that all required CI checks pass and address review feedback.

Do not include credentials, internal URLs, logs, or other sensitive information in contributions.
